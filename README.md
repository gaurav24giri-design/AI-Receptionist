# 🤖 AI Receptionist

An AI-powered receptionist designed to help small businesses manage customer enquiries and streamline communication.

## 🌟 Overview

AI Receptionist is a web-based application that helps businesses handle incoming customer enquiries through an AI-assisted interface. The project combines a web frontend with a backend API and cloud services.

## ✨ Features

* 💬 AI-assisted customer interaction
* 📩 Customer message handling
* 🖥️ Web-based receptionist interface
* 🛠️ Backend API powered by Cloudflare Workers
* 🗄️ Database integration using Cloudflare D1
* 🌐 Frontend hosting with Firebase Hosting
* 📊 Admin dashboard for reviewing enquiries

## 🧰 Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Cloudflare Workers, TypeScript
* **Database:** Cloudflare D1
* **Hosting:** Firebase Hosting
* **Development Tools:** Git, GitHub, npm

## 🚀 Getting Started

### Prerequisites

* Node.js and npm
* Git
* Firebase CLI (for Firebase deployment)
* Cloudflare account (for backend deployment)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/gaurav24giri-design/AI-Receptionist.git
   ```

2. Open the project folder:

   ```bash
   cd AI-Receptionist
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure required environment variables locally before running services that need them.

5. Refer to the backend configuration in `ai-receptionist-backend/` for Cloudflare Workers setup.

## 🔐 Security

* Keep API tokens, passwords, and private environment variables out of Git.
* Configure access control before exposing administrative or customer data.
* Never commit `.env` files or private credentials.
